# Rust Learning Journey

This repository contains my Rust learning examples and projects.

## Structure

- `basics/` - Fundamental concepts (variables, functions, control flow)
- `ownership/` - Ownership, borrowing, and lifetimes
- `error-handling/` - Result and Option types
- `projects/` - Small practice projects

## Running Examples

```bash
# Run a specific example
cd basics
```

```bash
cargo run --bin <module_name>
```


## Helpful Commands for Learning

```bash
# Format code (highly recommended!)
cargo fmt
```


```bash
# Check code for errors
cargo check
```

```bash
# Run with debug info
cargo run
```

```bash
# Build release version
cargo build --release
```

```bash
# Run tests
cargo test
```
